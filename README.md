# PaulFV.github.io

Stammseite für GitHub Pages (https://paulfv.github.io/).

- `index.html` – Startseite mit Links zu den Apps
  [G04Event](https://paulfv.github.io/G04Event/) und
  [G04EggX](https://paulfv.github.io/G04EggX/).
- `.well-known/assetlinks.json` – Digital Asset Links für die Android-Apps
  `de.g04event.app` (G04Event) und `de.g04eggx.app` (G04EggX). Ohne diese Datei
  zeigen die Apps eine Browser-Adressleiste. Muss an der Wurzel der Domain liegen.
- `.nojekyll` – damit GitHub Pages den Ordner `.well-known` veröffentlicht.
